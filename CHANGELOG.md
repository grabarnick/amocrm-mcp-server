# Changelog

## [0.2.0] - 2024-12-XX

### 🎉 Добавлено

#### Сделки (Leads)
- ✨ `getLead` - Получение конкретной сделки по ID
- ✨ `updateLead` - Обновление существующих сделок
- ✨ `deleteLead` - Удаление сделок
- ✨ `searchLeads` - Поиск сделок с фильтрацией
- ✨ `linkLeadToContact` - Связывание сделок с контактами
- ✨ `linkLeadToCompany` - Связывание сделок с компаниями

#### Воронки и этапы (Pipelines)
- ✨ `listPipelines` - Получение списка всех воронок
- ✨ `getPipeline` - Получение воронки с этапами
- ✨ `moveLeadToStatus` - Перемещение сделок по этапам воронки

#### Компании (Companies)
- ✨ `listCompanies` - Получение списка компаний с пагинацией
- ✨ `getCompany` - Получение компании по ID
- ✨ `createCompany` - Создание новых компаний
- ✨ `updateCompany` - Обновление существующих компаний
- ✨ `deleteCompany` - Удаление компаний
- ✨ `searchCompanies` - Поиск компаний

#### Задачи (Tasks)
- ✨ `listTasks` - Получение списка задач с фильтрацией
- ✨ `createTask` - Создание новых задач
- ✨ `updateTask` - Обновление существующих задач
- ✨ `completeTask` - Отметка задач как выполненных

#### Пользователи (Users)
- ✨ `listUsers` - Получение списка пользователей аккаунта
- ✨ `getUser` - Получение пользователя по ID

### 📝 Изменено
- 📖 Обновлена документация в README.md с описанием всех новых инструментов
- 📖 Добавлены примеры использования для всех категорий инструментов
- 📖 Создан файл NEW-FEATURES.md с подробным описанием новых возможностей

### 📊 Статистика
- **Добавлено инструментов:** 21
- **Общее количество инструментов:** 28 (было 7)
- **Покрытие API:** Сделки, Воронки, Компании, Задачи, Пользователи, Контакты, Заметки
