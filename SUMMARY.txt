✅ 1. MCP инструменты не были доступны в Claude Desktop
      Причина: Неправильный формат регистрации в src/mcp/tools.ts
      Решение: Переписаны все инструменты с использованием server.tool()

✅ 2. Ошибка "Redirect URI is not associated" при авторизации
      Причина: Шаблонный redirect_uri в .env
      Решение: Создано руководство OAUTH-GUIDE.md с решениями

✅ 3. Отсутствие инструментов для тестирования API отдельно от MCP
      Решение: Создан test-api.ts CLI с 7+ командами

БЫСТРЫЙ СТАРТ:
━━━━━━━━━━━━━━

Шаг 1: Соберите проект
  npm run build

Шаг 2: Протестируйте с помощью Inspector
  npx @modelcontextprotocol/inspector node dist/index.js

Шаг 3: Или подключите к Claude Desktop
  - Откройте: ~/Library/Application Support/Claude/claude_desktop_config.json
  - Используйте абсолютный путь к dist/index.js
  - Добавьте токены в env
  - Перезапустите Claude Desktop

Шаг 4: Если нужны новые токены
  npm run test-api auth <код_авторизации>
