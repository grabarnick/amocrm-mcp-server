# 🔑 Долгосрочные токены amoCRM

## 📋 Что это?

**Долгосрочный токен** (long-term token) в amoCRM — это специальный тип `access_token`, который:

- ✅ **Живет до 5 лет** (в нашем случае до 01.01.2027 — 447 дней)
- ✅ **Не требует refresh_token**
- ✅ **Не требует автообновления**
- ✅ **Упрощает интеграцию**

## 🆚 Сравнение с обычными токенами

| Характеристика | Обычный токен | Долгосрочный токен |
|---------------|---------------|-------------------|
| Срок действия | 24 часа | От 1 дня до 5 лет |
| Refresh token | Требуется | Не требуется |
| Автообновление | Необходимо | Не нужно |
| Сложность интеграции | Высокая | Низкая |
| Подходит для | Публичных интеграций | Конкретного аккаунта |

## 📖 Цитата из документации amoCRM

> **"Долгосрочные токены не имеют `refresh_token` и не требуют написания логики для их обновления."**

> **"В отличие от стандартных токенов, которые требуют регулярного обновления через `refresh_token`, долгосрочные токены действуют от 1 дня до 5 лет и не требуют обновления."**

Источник: [amoCRM OAuth Documentation](https://www.amocrm.ru/developers/content/oauth/step-by-step)

## 🔧 Как создать долгосрочный токен

### 1. Перейдите в amoCRM

1. Откройте **amoМаркет** → **Интеграции**
2. Выберите вашу интеграцию
3. Перейдите на вкладку **"Ключи"**

### 2. Сгенерируйте токен

1. Нажмите **"Сгенерировать токен"**
2. Выберите **дату окончания** (от 1 дня до 5 лет)
3. **Скопируйте токен** (показывается только один раз!)
4. Сохраните в безопасное место

### 3. Используйте в приложении

Долгосрочный токен используется вместо обычного `access_token`:

```bash
# В .env или DigitalOcean App Platform
AMO_LONG_TERM_TOKEN=eyJ0eXAiOiJKV1QiLCJhbGc...
```

## 🚀 Настройка в нашем проекте

### Локальная разработка

Добавьте в `.env`:

```env
AMO_LONG_TERM_TOKEN=ваш_долгосрочный_токен
```

### DigitalOcean App Platform

1. Откройте: https://cloud.digitalocean.com/apps/YOUR_APP_ID/settings
2. **Settings** → **App-Level Environment Variables**
3. Добавьте:
   ```
   AMO_LONG_TERM_TOKEN = ваш_долгосрочный_токен
   ```
4. **Save** → приложение перезапустится

## 🔍 Как работает код

### Автоматическое определение типа токена

Код автоматически определяет какой токен используется:

```typescript
// Определяем тип токена: долгосрочный или обычный
const isLongTermToken = !!cfg.AMO_LONG_TERM_TOKEN;
const accessToken = isLongTermToken ? cfg.AMO_LONG_TERM_TOKEN : cfg.AMO_ACCESS_TOKEN;
```

### Отключение автообновления

Для долгосрочных токенов автообновление не требуется:

```typescript
async function refreshTokensIfNeeded(): Promise<void> {
  // Для долгосрочных токенов обновление не требуется
  if (options.isLongTermToken) {
    if (!accessToken) {
      throw new Error('Долгосрочный токен не установлен.');
    }
    return;
  }
  
  // Логика для обычных токенов...
}
```

## 🔐 Безопасность

⚠️ **Важно:**

1. **Храните токен в секрете** — он дает полный доступ к вашему аккаунту
2. **Не коммитьте в Git** — используйте `.env` или переменные окружения
3. **Периодически обновляйте** — создавайте новый токен раз в год
4. **Отзывайте при утечке** — можно отозвать в интерфейсе amoCRM

## 📝 Преимущества долгосрочных токенов

✅ **Простота**
- Нет логики автообновления
- Нет refresh_token
- Меньше кода

✅ **Надежность**
- Не истекает каждые 24 часа
- Меньше точек отказа
- Стабильная работа

✅ **Производительность**
- Нет запросов на обновление токенов
- Меньше нагрузки на API amoCRM
- Быстрее работает

## 🔄 Миграция с обычных токенов

### Шаг 1: Создайте долгосрочный токен

См. раздел "Как создать долгосрочный токен"

### Шаг 2: Обновите переменные окружения

```bash
# Было (обычные токены)
AMO_ACCESS_TOKEN=short_lived_token
AMO_REFRESH_TOKEN=refresh_token

# Стало (долгосрочный токен)
AMO_LONG_TERM_TOKEN=long_lived_token
```

### Шаг 3: Перезапустите приложение

```bash
# Локально
npm run dev

# DigitalOcean
doctl apps create-deployment YOUR_APP_ID --force-rebuild
```
