# 🎉 Новые возможности AmoCRM MCP Server

## Обзор

Добавлено **22 новых инструмента** для полноценной работы с AmoCRM API v4, с фокусом на лиды, воронки и компании.

---

## 📋 Сделки (Leads) - 5 новых инструментов

### ✅ Что было
- `listLeads` - получение списка сделок
- `createLead` - создание сделок

### 🆕 Что добавлено

#### 1. `getLead` - Получить конкретную сделку
```json
{
  "tool": "amocrm.getLead",
  "arguments": { "id": 123456 }
}
```
**Использование:** Получение полной информации о сделке по её ID.

#### 2. `updateLead` - Обновить сделку
```json
{
  "tool": "amocrm.updateLead",
  "arguments": { 
    "id": 123456,
    "price": 15000,
    "status_id": 789,
    "responsible_user_id": 42
  }
}
```
**Использование:** Изменение параметров существующей сделки (цена, статус, ответственный и т.д.).

#### 3. `deleteLead` - Удалить сделку
```json
{
  "tool": "amocrm.deleteLead",
  "arguments": { "id": 123456 }
}
```
**Использование:** Удаление сделки из системы.

#### 4. `searchLeads` - Поиск сделок
```json
{
  "tool": "amocrm.searchLeads",
  "arguments": { 
    "query": "важн",
    "pipeline_id": 123,
    "status_id": 456,
    "responsible_user_id": 42,
    "limit": 50
  }
}
```
**Использование:** Поиск сделок по тексту, фильтрация по воронке, статусу, ответственному.

#### 5. `linkLeadToContact` - Связать сделку с контактом
```json
{
  "tool": "amocrm.linkLeadToContact",
  "arguments": { 
    "lead_id": 123456,
    "contact_id": 789012
  }
}
```
**Использование:** Создание связи между сделкой и контактом.

#### 6. `linkLeadToCompany` - Связать сделку с компанией
```json
{
  "tool": "amocrm.linkLeadToCompany",
  "arguments": { 
    "lead_id": 123456,
    "company_id": 789012
  }
}
```
**Использование:** Создание связи между сделкой и компанией.

## 🎯 Воронки и этапы (Pipelines) - 3 новых инструмента

### 🆕 Что добавлено

#### 1. `listPipelines` - Получить все воронки
```json
{
  "tool": "amocrm.listPipelines",
  "arguments": {}
}
```
**Использование:** Получение списка всех воронок продаж в аккаунте.

#### 2. `getPipeline` - Получить воронку с этапами
```json
{
  "tool": "amocrm.getPipeline",
  "arguments": { "id": 123 }
}
```
**Использование:** Получение информации о конкретной воронке, включая все её этапы.

#### 3. `moveLeadToStatus` - Переместить сделку по этапам
```json
{
  "tool": "amocrm.moveLeadToStatus",
  "arguments": { 
    "lead_id": 123456,
    "status_id": 789,
    "pipeline_id": 123
  }
}
```
**Использование:** Перемещение сделки в другой статус (этап воронки), возможно с изменением воронки.

## 🏢 Компании (Companies) - 6 новых инструментов

### ✅ Что было
- Ничего (только упоминание в `createNote`)

### 🆕 Что добавлено

#### 1. `listCompanies` - Получить список компаний
```json
{
  "tool": "amocrm.listCompanies",
  "arguments": { "page": 1, "limit": 25 }
}
```
**Использование:** Получение списка компаний с пагинацией.

#### 2. `getCompany` - Получить компанию по ID
```json
{
  "tool": "amocrm.getCompany",
  "arguments": { "id": 123456 }
}
```
**Использование:** Получение полной информации о компании.

#### 3. `createCompany` - Создать компанию
```json
{
  "tool": "amocrm.createCompany",
  "arguments": { 
    "name": "ООО Рога и Копыта",
    "custom_fields_values": [...]
  }
}
```
**Использование:** Создание новой компании в системе.

#### 4. `updateCompany` - Обновить компанию
```json
{
  "tool": "amocrm.updateCompany",
  "arguments": { 
    "id": 123456,
    "name": "ООО Новое название",
    "custom_fields_values": [...]
  }
}
```
**Использование:** Изменение данных существующей компании.

#### 5. `deleteCompany` - Удалить компанию
```json
{
  "tool": "amocrm.deleteCompany",
  "arguments": { "id": 123456 }
}
```
**Использование:** Удаление компании из системы.

#### 6. `searchCompanies` - Поиск компаний
```json
{
  "tool": "amocrm.searchCompanies",
  "arguments": { 
    "query": "рога",
    "limit": 50
  }
}
```
**Использование:** Поиск компаний по названию или другим параметрам.

## ✅ Задачи (Tasks) - 4 новых инструмента

### 🆕 Что добавлено

#### 1. `listTasks` - Получить список задач
```json
{
  "tool": "amocrm.listTasks",
  "arguments": {
    "entity_type": "leads",
    "entity_id": 123456,
    "responsible_user_id": 42,
    "is_completed": false,
    "limit": 25
  }
}
```
**Использование:** Получение списка задач с фильтрацией по сущности, ответственному, статусу выполнения.

#### 2. `createTask` - Создать задачу
```json
{
  "tool": "amocrm.createTask",
  "arguments": {
    "entity_type": "leads",
    "entity_id": 123456,
    "text": "Позвонить клиенту",
    "complete_till_at": 1704067200,
    "responsible_user_id": 42,
    "task_type_id": 1
  }
}
```
**Использование:** Создание новой задачи для сделки, контакта, компании или покупателя.

#### 3. `updateTask` - Обновить задачу
```json
{
  "tool": "amocrm.updateTask",
  "arguments": {
    "id": 789012,
    "text": "Обновленный текст",
    "complete_till_at": 1704153600,
    "is_completed": false
  }
}
```
**Использование:** Изменение параметров задачи.

#### 4. `completeTask` - Выполнить задачу
```json
{
  "tool": "amocrm.completeTask",
  "arguments": { "id": 789012 }
}
```
**Использование:** Отметка задачи как выполненной.

## 🚀 Практические сценарии использования

### Сценарий 1: Работа с воронкой продаж
```json
// 1. Получить все воронки
{ "tool": "amocrm.listPipelines" }

{ 
  "tool": "amocrm.searchLeads", 
  "arguments": { "status_id": 456, "limit": 50 }

{ 
  "tool": "amocrm.moveLeadToStatus", 
  "arguments": { "lead_id": 123456, "status_id": 789 }
```

```json

{ 
  "tool": "amocrm.createLead", 
  "arguments": { "name": "Сделка с ООО Новая компания" }

{ 
  "tool": "amocrm.linkLeadToCompany", 
  "arguments": { "lead_id": 123456, "company_id": 789012 }

// 4. Создать задачу по работе с компанией
{ 
  "tool": "amocrm.createTask",

    "entity_type": "companies",

    "text": "Подготовить коммерческое предложение",
```

```json
{ 
  "tool": "amocrm.getLead", 
  "arguments": { "id": 123456 }

// 3. Обновить бюджет сделки
{ 
  "tool": "amocrm.updateLead",
```

## 💡 Советы по использованию

1. **Используйте поиск вместо перебора:** `searchLeads` и `searchCompanies` эффективнее, чем перебор всех записей
2. **Кэшируйте данные воронок:** `listPipelines` возвращает статичные данные, которые можно кэшировать
3. **Проверяйте пользователей:** Используйте `listUsers` для получения актуальных ID пользователей
4. **Связывайте сущности:** Используйте `linkLeadToContact` и `linkLeadToCompany` для создания связей
5. **Управляйте задачами:** Создавайте задачи для отслеживания действий по сделкам
